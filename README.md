# EIGHTCOUNT · 八拍全球舞蹈索引

按歌曲、歌手/组合、音乐市场、平台及视频类型查找舞蹈视频。

当前收录 228 首歌曲、141 个艺人署名条目、276 条公开视频来源，涵盖韩流、华语、欧美、日本等音乐市场。

B站与 YouTube 通过原平台播放器按需嵌入；抖音提供原站入口。保留原发布者、视频链接和核对范围，不托管视频文件。公开可见不等于转载授权，播放受平台、地区和作者设置影响。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 / (root)。本站为无构建依赖的静态 HTML/CSS/JavaScript，使用相对资源路径。

## 内容及授权

网站界面代码与第三方视频、预览图的权利分开处理。视频和预览图版权归各权利人；预览图来源见歌曲详情。此仓库未授予第三方素材的转载许可。
